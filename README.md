# Product Manager Exercise — Summer 2027

You have real (anonymized) telemetry from a fleet of vehicles over one week.
Read `PROBLEM_STATEMENT.md`, then `GUIDELINES.md`.

## Setup

This repo uses [Git LFS](https://git-lfs.com/) for the larger data files:

```
git lfs install
git lfs pull
```

The data is in `data/raw/`. That is everything you get.
